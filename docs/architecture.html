Security controls

  • Network — instance in a public subnet of LabVPC; security group opens TCP 8080 to my IP /32 only, never 0.0.0.0/0.
  • IAM — no access keys stored on disk; Docker logs in to ECR with a short-lived token from the lab role. Least-privilege policy: infra/iam-least-privilege-policy.json.
  • ECR — private repository, scan on push, AES-256 encryption, lifecycle rule.
  • Container — non-root user, 256 MB / 0.5 CPU limits, health check, restart policy.
  • App — input validation, parameterised SQL (no SQL injection).
